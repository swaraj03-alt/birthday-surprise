# Birthday Surprise Website 💝

A mobile-first interactive birthday website with a passcode screen, three clickable gifts, a birthday camera page, interactive wish cake, photo memories, love letter and final message.

## Open the website
- Open `index.html` in a browser, or upload the whole folder to GitHub.
- Passcode: `1234`

## Gift flow
1. Gift 1: birthday photo page → make-a-wish cake → four-photo memories gallery.
2. Gift 2: personal letter with portrait.
3. Gift 3: final message page.

## Photos already included
All six supplied photos are in `assets/photos/` and connected to the pages.

## Publish free with GitHub Pages (phone-friendly)
1. Sign in to GitHub in Chrome and create a **Public** repository (for example `birthday-surprise`).
2. Upload the ZIP contents (not the ZIP itself): open the repository → **Add file** → **Upload files**. If GitHub mobile view hides this option, use Chrome's **Desktop site** setting.
3. Upload `index.html`, `css/`, `js/`, `assets/`, and `README.md`, then commit.
4. Open repository **Settings → Pages**. Under Build and deployment choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait a minute or two. GitHub will show your public URL, usually `https://YOUR-USERNAME.github.io/birthday-surprise/`.

## Personalise
- Change `Demo` and the letter text in `index.html`.
- Change `PASSCODE` near the top of `js/script.js`.

## Privacy
GitHub Pages sites in public repositories are publicly accessible. Anyone with the URL can view the photos and messages. Do not publish private images unless the recipient is comfortable with that. The passcode is only a playful front-end gate, not real security.
